## 🚀 Proyectos

### 🧾 Personal App – Registro de datos personales

Aplicación Android que simula un formulario de registro de datos personales y envía la información a otra pantalla (Activity).

#### ✨ Funcionalidades principales:

- Uso de **ViewBinding**
- Diseño de formularios con:
  - Inputs de texto
  - Selector desplegable (Spinner)
  - CheckBox
  - Botones
- Manejo de eventos de click
- Validación de campos antes del envío
- Uso de **Dialogs**:
  - Confirmación de envío de datos
  - Validación de checkbox obligatorio
- Envío de datos a otra Activity mediante **Intent extras**

#### 📤 Flujo de la aplicación:

1. El usuario ingresa:
   - Nombre
   - Distrito
   - Estado civil
2. Se valida que los campos estén completos
3. Se verifica aceptación mediante CheckBox
4. Se muestra un diálogo de confirmación
5. Si se confirma, los datos se envían a una segunda Activity
6. La segunda pantalla muestra la información recibida
